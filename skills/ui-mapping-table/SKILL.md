# Mapping table operations

Use the DataGrid procedure, then apply mapping semantics: identify the module/channel and mapping field, validate the requested value against the published capability and domain constraints, edit only the authorized cell, commit, re-read the same semantic row, and capture row evidence. Detect duplicates or overlap before applying. Restore every changed mapping and verify the restored row.
